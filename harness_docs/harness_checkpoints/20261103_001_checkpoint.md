## Резюме сессии 2026-11-03

Единая конвенция харнес-репозиториев: `_{каталог}_` → `harness_{каталог}`.
Причина — агенты систематически нормализуют `_{каталог}_` до `docs/` и роняют
подчёркивания. Эталон — lm_hrdo_2, задача 20261102_940.

- **git mv**: `_docs_/_checkpoints_` → `harness_checkpoints`, `_phases_` →
  `harness_phases`, `_tasks_` → `harness_tasks`, затем `_docs_` → `harness_docs`.
- **Перезапись ссылок**: `misc/harness_dir_rename.py` (скопирован из lm_hrdo_2),
  итог **505 замен в 118 файлах**: код (8 файлов `src/` — докстринг-ссылки на
  дизайн-доки), доки, `.zcode/plans`, AGENTS.md, README, ONBOARDING, LESSONS.
- **Правки скрипта против эталона**: `SKIP_DIRS` −`src` +`dbpm-portable`
  (в вендорённом pydantic идентификаторы `_docs_for_groups` — ложные совпадения
  по подстроке); `SKIP_FILES` +исторические `move_docs_dirs.py`/
  `rename_docs_dirs.py`; backslash-правила (`_docs_\_checkpoints_` — в этом
  репо Windows-пути в доках); bare-правила `_tasks_/…` через regex с guard'ом
  слева (в `harness_checkpoints/` подстрока `_checkpoints_/` есть — простой
  replace дал бы двойной префикс). Скрипт идемпотентен.
- **Ручные правки** bare-прозы: три конвенции (CHECKPOINTS/TASKS/PHASES,
  включая дерево структуры). Исторические доки (старые чекпойнты, `.zcode/plans`
  в прозе) не правились — история.
