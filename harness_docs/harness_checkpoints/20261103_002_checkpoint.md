## Key decisions & constraints

- qr-репо остаётся **без remote** (решение пользователя 2026-11-03).
- Phase 20 занята table-profiling — новая фаза нумеруется 21.
- Case-insensitive lookup — изменение общего парсера; для lowercase-миров
  (PG/GP/qr) поведение идентично, регресс зелёный.
- Snowflake extra не входит в базовые зависимости; unit-тесты идут без
  драйвера (фейк в sys.modules / фикстуры / offscreen Qt).
- MCP-деплой требует `mcp.allow_deploy: true`; правки общего инструмента
  прогонять на PG/GP/CH-регрессе.
