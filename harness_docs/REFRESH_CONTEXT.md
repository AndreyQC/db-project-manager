## Получить контекст проекта

Прочитай следующие файлы
```
 - harness_docs\harness_checkpoints\CHECKPOINTS_CONVENTION.md
 - harness_docs\harness_tasks\TASK_CONVENTIONS.md
 - harness_docs\harness_phases\PHASES_CONVENTION.md
 - LESSONS_LEARNED.md
 - README.md
```
 После этого прочитай последний чекпойнт и обнови контекст
просмотри последний чекпойнт используя команду
```bash
ls -la harness_docs/harness_checkpoints/
```
 Не читай другие файлы если контекста уже достаточно
