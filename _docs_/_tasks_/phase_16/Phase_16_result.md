## 4. Ключевые решения

- **GP-only знание не протекает в PG-путь**: админ-схемы, gp-запросы и
  свёртки живут за веткой `_is_greenplum`/capability-пробой; PG-запросы
  текстуально неизменны, где возможно (§70-4, §71-3).
- **Системные/сервисные схемы не сравниваются** (gp_toolkit — 16.5,
  `__deploy` — 16.8): инструмент не диффует собственное runtime-состояние и
  системные каталоги вендора.
- **Канонизации — конечный перечень пар** «каталог ↔ рукописный DDL»,
  закрытых построчным сравнением живых пар (§72-4), а не генеративные правила.
- **pg_dump-модель для serial**: свёрнутая колонка + невыделяемая
  последовательность (16.10) вместо диффа артефакта serial.
