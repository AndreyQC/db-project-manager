## Реализовано (Phase 15.7)

- Уникальные run-подкаталоги `<output-dir>/<timeline-name>/` для `compare run`,
  `deploy analyze`, `deploy plan`, `deploy apply`; `--no-run-subdir` = плоская раскладка.
- DB-side RE-snapshot сохраняется в `<run>/target/`/`source/`; rehearsal RE — в `<run>/rehearsal_re/`.
- `project.build: false` исключается из diff обеих сторон + счётчик в отчётах.
- `reltuples=-1` → «нет статистики (не ANALYZEd)».
- Закрыты 3 класса false-positive CHANGED (LESSONS §66–§67):
  text-cast в DEFAULT колонок; bare `SERIAL`/`BIGSERIAL`/`SMALLSERIAL`; serial→NOT NULL.

## Ключевые решения и ограничения

- **Run-каталог создаёт граница команды (CLI/GUI), не сервисы** — сервисы не
  изменили сигнатуры; unit-тесты сервисов не тронуты; вложенности run-каталогов нет.
- **build=false исключается из ОБЕИХ сторон** (иначе объект из БД стал бы REMOVED).
- **Канонизацию text-cast применяем и в пути колонок**, не только в hash тела.
- **Окружение:** Device Guard блокирует `.venv\Scripts\python.exe` (os error 4551).
  Обход для тестов/CLI: кэшированный интерпретатор uv +
  `PYTHONPATH="src;.venv/Lib/site-packages"`; ruff — `.venv/Scripts/ruff.exe`.
