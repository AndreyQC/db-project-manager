## Проблема: CH HTTP API и DDL-фильтр по базе

`clickhouse-connect` (Python-клиент) и `curl` к CH-эндпоинту
дают несогласованные ответы:
- `SELECT FROM system.tables WHERE database='cis_etl'` — успех
- `DROP TABLE cis_etl.test_table` — `Code: 81. Database cis_etl does not exist`
- `SHOW DATABASES` без параметра — `cis_zup` (без `cis_etl`)
- `SHOW DATABASES` с `?database=cis_etl` — пустой результат

Вывод: фильтр `database` в URL работает только для SELECT в рамках сессии.
Для DDL нужен прямой grant на базу — `hrdo_user` его не имеет.
Это блокирует `DROP TABLE` через `clickhouse-connect` даже когда таблица
существует (verified через `SELECT name FROM system.tables`).

**Workaround для очистки:** попросить DBA выдать grant
`GRANT DROP ON cis_etl.* TO hrdo_user`.
