## Кластер CH и поведение DDL

CH на 10.41.254.51:31023 — это **3-шардовый кластер** (`cluster=default`,
shards 1/2/3, replicas 1), сервер `bi-clickhouse-1-0-0` мы попадаем на
шард 2.

**Проверено `default`-суперюзером** (connection
`10_41_254_51_CH__DB__default__U_default.yaml`):
```sql
SHOW GRANTS FOR default → GRANT ALL ON *.* TO default WITH GRANT OPTION
```

**Главное открытие — рассинхрон кластера.** База `cis_etl` создана **только
на 2 из 3 реплик**:
```
bi-clickhouse-1-0-0  ✓  (наш текущий)
bi-clickhouse-0-0-0  ✓
bi-clickhouse-2-0-0  ✗
```

Из-за этого:
- `SELECT FROM system.tables WHERE database='cis_etl'` — попадает на
  реплику с базой → возвращает 10 объектов.
- `SELECT ...` на реплике без базы → `Code: 81. Database cis_etl does not
  exist`.
- `clickhouse-connect` с `database='cis_etl'` в init — падает на инициализации
  (запрос `system.settings` уходит на «пустую» реплику).
- `DROP TABLE cis_etl.test_table` через HTTP — retry 5 раз сработал (попал
  на «правильную» реплику). `test_table` удалена.

**Выводы для адаптера:**

1. Суперюзер `default` есть, пароль зашифрован в
   `connections/10_41_254_51_CH__DB__default__U_default.yaml`. Пароль
   расшифрован через `Fernet(ENVOS_CRYPTO_01)`.

2. DDL-операции работают, но **нужны retry** при ошибке
   `UNKNOWN_DATABASE` (81) — это признак попадания на пустую реплику.

3. Для надёжности в `CHDatabaseAdapter`:
   - использовать `default`-юзера для RE/deploy (полные права);
   - в `command()` ловить `DatabaseError` с кодом 81 и retry 3-5 раз;
   - либо `INSERT INTO system.zookeeper ...` для синхронизации (нужен
     root-доступ к ZK).

4. **Рекомендация DBA:** выполнить `CREATE DATABASE cis_etl ON CLUSTER
   default` для восстановления базы на 3-й реплике. Сейчас
   распределённые DDL (`ON CLUSTER`) могут расходиться.

## Workaround для `clickhouse-connect` на рассинхронном кластере

```python
import clickhouse_connect
c = clickhouse_connect.get_client(
    host='10.41.254.51', port=31023,
    username='default', password='<decrypted>',
    send_receive_timeout=30,
    # НЕ передавать database='cis_etl' — иначе init падает
)
# Использовать полные имена: cis_etl.table_name
c.command('DROP TABLE cis_etl.test_table')
```

При ошибке `UNKNOWN_DATABASE` — повторить 3-5 раз.
