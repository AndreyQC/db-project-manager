## Что это за проект

Python 3.13 инструмент для PostgreSQL/Greenplum: reverse-engineering БД → дерево
SQL-файлов, граф зависимостей, validation deploy, compare, controlled-deployment
с safety-gate и репетицией, GUI на PySide6. Стек: `uv`, pydantic v2, typer,
PySide6, sqlglot. Слои: `domain → infrastructure → application → presentation`.

## Ключевые решения и ограничения

- GP-only знание за `_is_greenplum`/capability-пробами; PG-запросы неизменны
  (LESSONS §70-4, §71-3).
- Системные/сервисные схемы (gp_toolkit, `__deploy`) не сравниваются —
  инструмент не диффует собственное runtime-состояние (§71, §73).
- `--include-drops` — согласие включить дропы в план, НЕ обход data-gate
  (CD-9/CD-10): таблицы с данными/недоказуемо пустые блокируются; пустые
  без статистики — fail-safe «unknown = есть данные» → лечится ANALYZE.
- Окружение: venv рабочий (`uv sync --system-certs`); Device Guard-обход из
  §68 более не требовался.
