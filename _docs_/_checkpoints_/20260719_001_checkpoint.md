## 1. What this project is

`db-project-manager` — open-source SSDT-equivalent for PostgreSQL/Greenplum:
reverse-engineer DB catalog → typed file tree with autodoc headers →
dependency graph → validation deploy to temp DB → (future) migrations.

- **Language:** Python 3.13+, `uv` for env/package management
- **Stack:** PySide6 (GUI), typer (CLI), SQLAlchemy + psycopg2 (PG), pydantic,
  Jinja2, loguru, cryptography (Fernet passwords)
- **Layout:** layered — `domain` → `infrastructure` → `application` → `presentation`

## 5. Key decisions & constraints

- **UI-only connection creation**; CLI consumes `--connection-file <path>`.
- **`.dbm_graph/` gitignored** — deterministic rebuild from codebase.
- **Cleanup temp DB by default** (`--keep-db` to keep; GUI checkbox off by default).
- **No QScintilla** — `pyside6-scintilla` abandoned, `bscintillaedit` has no wheel (needs C++ build). Phase 1 uses `QPlainTextEdit + QSyntaxHighlighter`. Re-evaluate in Phase 3.
- **uv + corporate TLS proxy:** `unset SSL_CERT_FILE REQUESTS_CA_BUNDLE CURL_CA_BUNDLE && uv sync` (uv/rustls ignores these vars; pip uses them).
- **No secrets in git:** `connections/` and `config.yaml` gitignored; passwords Fernet-encrypted, key in env.
- **Generic parser interface** — `ObjectGraphParser` ABC designed for reuse beyond SQL (Informatica, Airflow).
