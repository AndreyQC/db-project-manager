## Реализовано (поверх чекпойнта 20261009_001)

- **20261009_002** (feedback Сергея, cis_zup, GP): `deploy apply` падал на
  `DROP FUNCTION IF EXISTS ...;` — `syntax error at or near ";"`. Корень: не
  `;`, а отсутствие списка аргументов — ядра < PG 10 (GP 6 = PG 9.4) требуют
  `(...)` в грамматике. Фолбэк `args = "()"` в `_drop_statement` (коммит
  `65abe4c`). «Пропавшая» правка Сергея в историю репо не попадала (pickaxe/
  reflog) — бандл, пересобранный 2026-10-07, вернул баг. LESSONS §78.
- **20261009_003** (уровень 2, реализовано 2026-10-11): сигнатуры REMOVED-
  рутин через `ObjectSnapshot.argument_types` → `PlannedOperation` → DROP
  по настоящей перегрузке; fail-safe BLOCKED при неизвестной сигнатуре
  вместо тихого no-op `IF EXISTS` (коммиты `da59f2d`, `331d7d8`). Один
  `classify()` покрывает deploy plan / повторную дельту apply / MCP.
- **ONBOARDING.md** (новый корневой док): порядок чтения первого дня,
  Minimax prod-настройки (`reksoft-sputnik-prd`, base URL, `minimax-m2`,
