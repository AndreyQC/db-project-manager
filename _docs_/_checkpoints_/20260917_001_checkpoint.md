## Ключевые решения (кратко; детали — final doc D1–D11)

- D9: content-drop для схем из кода и `public` (оболочки, ACL, владельцы,
  default privileges сохраняются; deploy видит UNCHANGED); полный DROP — только
  «мусорным» схемам, которых нет в коде. Причина: кодовая база не знает о правах
  (голый `CREATE SCHEMA` + COMMENT, RE не читает ACL).
- D2: `__deploy` живёт: `schema_version` сохранён, journal-таблицы TRUNCATE —
  pre/post/seed перезапустятся.
- D11: вся специфика GP — в postgres-адаптере; новый тип СУБД = адаптер +
  регистрация + `SUPPORTED_DB_TYPES`.
- Отклонение от final doc §4.5: GUI-подтверждение — чекбокс-гейт в диалоге
  (паттерн LESSONS §43) вместо двухшагового dry-run→confirm (поток воркера не
  может показать диалог); двухшаговый обзор списка схем доступен через
  `--dry-run` в CLI. Индикатор флага в списке подключений не делали
  (модель списка — только имена).
