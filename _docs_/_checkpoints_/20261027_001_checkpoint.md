## Резюме сессии 2026-10-27

Потребитель `hrdo_ods` (Greenplum, внешние таблицы PXF) — LOCATION и имена
схем меняются per-workspace. Реализован общий механизм подстановки параметров:

- **Плейсхолдеры `{{name}}`** в теле SQL заменяются **до парсинга** — граф,
  дельта и исполняемые скрипты строятся на развёрнутых именах (параметризация
  схем не ломает `object_key`/рёбра).
- **Источники значений** (приоритет): `dbpm.params.yaml` кодовой базы
  (секция `parameters:`) → `params:` в `connections/*.yaml` →
  `--param name=value` CLI (повторяемый; на `graph build` / `deploy validate` /
  `deploy plan` / `deploy apply`).
- **Крипта**: `crypto__<ENV>__<token>` расшифровывается готовым `crypto_util`
  последним шагом, строго (нет env-ключа → падение деплоя). Значения не
  попадают в логи/ошибки — только имена параметров и файлы.
- **Fail-fast**: неразрешённый плейсхолдер валит команду с агрегированным
  списком «параметр → файлы» (`UnresolvedParamError`), exit 2.
- **Autodoc-заголовок исключён** из подстановки (identity уже развёрнута RE);
  `dbpm.manifest.json` не затронут — отдельный файл параметров переживает
  перегенерацию манифеста.
- Проброс во всю цепочку: snapshot (тела для `sql_hash`) → compare → delta
  (артефакты) → deploy validate/apply + rehearsal.

Попутно: найден на живом CLI-смоуке и исправлен до коммита баг семантики —
переданный словарь параметров трактуется **всегда как переопределения поверх
файла** (иначе пустой CLI-набор подавлял `dbpm.params.yaml`).

| Область | Путь | Заметка |
|---|---|---|
| Резолвер | `infrastructure/params/resolver.py` | load/effective_params, крипта, ParamsFileError/UnresolvedParamError |

| Сервисы | `application/{graph_service,compare_service,delta_service,deploy_service,deploy_apply_service}.py` | `params`-проброс (build/deploy_order/run/plan/apply) |

| CLI | `presentation/cli/main.py` | `--param` x4, `_parse_cli_params` (режет по первому `=`), обработка UnresolvedParamError |

GUI/MCP без изменений: `params=None` → файловые значения по умолчанию.

## Key decisions & constraints

- Переданный `params` — всегда **переопределения поверх** `dbpm.params.yaml`
  (файл — базовый слой; пустой словарь не подавляет файл).
- Подстановка строгая и для `build: false`-файлов; `{{9x}}`/`{{a.b}}` — не
  плейсхолдеры (остаются в тексте).
- Манифест не расширялся: параметры живут в отдельном `dbpm.params.yaml`
  (имя зафиксировано пользователем).
- MCP-деплой требует `mcp.allow_deploy: true`; правки общего инструмента
  прогонять на PG/GP/CH-регрессе.
