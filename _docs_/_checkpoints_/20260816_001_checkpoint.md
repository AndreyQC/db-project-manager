## Что это за проект

Python-инструмент (PostgreSQL/Greenplum) для reverse-engineering БД в дерево SQL-файлов,
построения графа зависимостей, validation deploy на пустую temp-БД, сравнения состояний
и controlled-deployment с safety-gate и репетицией. Стек: Python 3.13, uv, pydantic v2,
typer (CLI), PySide6 (GUI), sqlglot, testcontainers. Пакеты: `domain` → `infrastructure`
→ `application` → `presentation`.

## Key decisions & constraints (новое в Phase 12)

- SQL-тело — единственный источник правды для колонок (ALT-1b): дрейф
  autodoc↔SQL невозможен по построению; autodoc остаётся identity-only.
- Репетиция вместо mega-транзакции (ALT-5): сбой = отладка на аналоге;
  восстановление повторным apply (пересчёт дельты + идемпотентные pre/post).
- Консервативная матрица ALT-3: до таблиц с данными авто-дельта доносит только
  SAFE (ADD nullable/literal-default, widening, comments); остальное — pre-скрипт.
- Gate-residual даунгрейд: табличный gate Phase 11 уточняется колоночной
  классификацией; нет отчёта — нарушения действуют (fail-safe).
- Идентификация при сравнении не включает имя БД (§51) — compare работает
  между средами/клонами.
