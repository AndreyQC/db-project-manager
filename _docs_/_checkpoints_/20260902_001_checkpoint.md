## Что это за проект

Python 3.13 инструмент для PostgreSQL/Greenplum: reverse-engineering БД → дерево SQL-файлов,
граф зависимостей, validation deploy на temp-БД, сравнение состояний,
controlled-deployment с safety-gate и репетицией, GUI на PySide6. Стек: `uv`,
pydantic v2, typer (CLI), PySide6 (GUI), sqlglot, testcontainers. Пакеты:
`domain → infrastructure → application → presentation`.

## Key decisions & constraints (новое в Phase 15)

- **PRE-1: Plan Viewer — отдельное окно.** `DeltaPlan` и `DiffReport` имеют
  разные контракты (PlannedOperation vs DiffEntry), разные фильтры и цвета;
  чистое разделение по конвенции Phase 14.
- **PRE-2: Preflight-чекбокс + красный заголовок.** Один шаг, не проматывается
  Enter'ом, тестируется атрибутом `isEnabled()`. `confirm_understands_risk` —
  GUI-side only, не часть CLI-контракта.
- **PRE-3: Chain через Plan Viewer.** После успешного plan/apply — кнопка
  «Открыть план» в QMessageBox. Plan Viewer получает prefill
  (`target_connection`/`codebase_dir`/`output_dir`); кнопка «Применить…» в
  тулбаре открывает `DeployApplyDialog` с теми же значениями.
- **Урок §42, §43, §40, §44 применены явно** (см. Plan Viewer и DeployApplyDialog).
- **QAction trigger в offscreen-тестах**: `setChecked(False)` сам по себе не
  вызывает `triggered` — handler вызывается напрямую в тесте (lesson §60).
