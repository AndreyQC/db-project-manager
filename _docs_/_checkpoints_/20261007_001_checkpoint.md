## Что это за проект

db-project-manager (db-pm) — Python-инструмент управления схемами
PostgreSQL/Greenplum: reverse-engineering БД в файловую кодовую базу,
граф зависимостей объектов, diff, дельта-планы, деплой с safety gate,
SQL-профайлинг таблиц, MCP-сервер. Stack: Python 3.13, typer (CLI),
PySide6 (GUI), FastMCP, SQLAlchemy/psycopg2, sqlglot, pydantic v2, uv.
Портативный бандл `dbpm-portable/` (вне git) — запуск на машинах без uv.

## Ключевые решения и ограничения

- Три независимых read-only барьера: (1) генераторы выдают только SELECT;
  (2) классификатор fail-closed перед исполнением; (3) серверная
  RO-транзакция с безусловным ROLLBACK на отдельном соединении.
- Синтетические тесты генератора проверяют форму, не исполнимость SQL —
  представительные типы каждого маршрута проверять на живой БД (LESSONS §77).
- Отчёты профайлинга — `reports/` (gitignored, PII-агрегаты) — не
  копировать в общедоступные места; в бандле отчёты падают рядом с ним.
- Пароль подключения: интерактивный ввод при отсутствии env-ключа
  (предпочтительно) или plaintext в yaml бандла (вариант A).
- Инциденты окружения: DNS-негативный кэш при VPN+домашняя сеть
  (лечится `ipconfig /flushdns`); uv требует unset SSL_CERT_FILE
  (корпоративный прокси, LESSONS §1).
