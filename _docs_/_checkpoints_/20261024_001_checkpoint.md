## Резюме сессии 2026-10-24

Задача выросла из проекта-потребителя `qr-db-miroslav-asisay` (QR Память,
PostgreSQL 18, 87 таблиц, 316 функций): db-pm не поддерживал индексы как
объекты деплоя и не имел пути засева данных. За сессию:

- **Индекс — полноценный объект**: парсер (CREATE [UNIQUE] INDEX + ребро
  `index → table`), RE-выгрузка (`pg_get_indexdef`, constraint-backed
  исключены), шаблон `<schema>/indexes/index <name>.sql`, MCP-маппинг,
  participation в дельте (`DIFFED_TYPES += index`).
- **Постдеплойный засев**: qr-сиды конвертированы в
  `__migrations/post/` (1118 городов и др.), README с конвенциями pre/post/seed.
- **Попутные фиксы db-pm** (все найдены живым прогоном):
  identity-колонки (RE их терял — сид падал NotNullViolation),
  пустые схемы в RE (дельта не была возобновляемой), entry point
  `db-pm-mcp` (CLI-аргументы игнорировались), compare DB-снапшоты без
  qualify_refs (150 ложных CHANGED).
- **Сквозная приёмка**: MCP `deploy_apply` в чистую БД
  `qr_apply_20261024_165050` — 533 объекта, 123 индекса, сиды,
  идемпотентный повтор; compare с эталоном `qr_memory_dev`
  **added=0 removed=0 changed=0 unchanged=533**.

## Known gaps / NOT done

1. Serial-последовательности: standalone-файл + serial-колонка → дубль
   `*_seq1` при validate-деплое (нужен serial-folding в граф-пути).
2. `normalize_sql` не хэширует хвостовые ALTER TABLE — FK вне CREATE TABLE
   невидимы compare (2 взаимных FK qr-проекта не видны).
3. Extensions не в дельте — чистая БД требует ручного `CREATE EXTENSION`
   (qr_apply: plpgsql, citext, pgcrypto).
4. PG pre-flight `ensure_deploy_tables` — только CH; PG требует
   `deploy init-service-schema` перед первым apply.
5. Репетиция apply на пустом таргете reject (RE штампует свежий calver) —
   обход `rehearsal=false`.
6. Из 20261023_588: 17 триггеров `build: false`, 2 взаимных FK, гранты,
   constraint-объекты.

## Key decisions & constraints

- Автогенерация индексов под FK — **отклонена пользователем**; индекс —
  внешний объект, не инлайн в CREATE TABLE (модель pg_dump).
- PK/UNIQUE-констрейнты остаются инлайн; constraint-backed индексы
  исключены из RE.
- CH вне скоупа индексов (data-skipping индексы живут в DDL таблицы,
  `indexes: []` по контракту).
- MCP-деплой требует `mcp.allow_deploy: true` в yaml подключения;
  connections-dir передаётся через `--connections-dir` (работает после
  фикса entry point).
- Правки общего инструмента прогонять на PG/GP/CH-регрессе (1320 тестов).
