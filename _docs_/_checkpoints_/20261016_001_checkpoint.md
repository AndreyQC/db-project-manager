## Новая задача: 20261016_001 — Поддержка Clickhouse

**План:** `_tasks_/2026-10-16/20261016_001_clickhouse_support_plan.md`

**Цель:** добавить полноценную поддержку Clickhouse:
- Доступ к БД (драйвер `clickhouse-connect`)
- Reverse engineering (таблицы, MV, словари, функции)
- Deploy apply
- Deploy validate

**Ключевые изменения:**
1. Новый адаптер `CHDatabaseAdapter(DatabaseAdapter)`
2. Регистрация в `infrastructure/database/registry.py`
3. `"clickhouse"` в `domain/connection.SUPPORTED_DB_TYPES`
4. `"clickhouse"` в `infrastructure/sql/classify.DB_TYPE_DIALECT`

**Особенности Clickhouse:**
- Нет схем в PG-смысле — «database» = namespace
- Нет CONSTRAINT (primary key = ORDER BY в движке)
- Нет транзакций в PG-стиле
- Типы таблиц: MergeTree, Log, Memory, etc.
- MATERIALIZED/EPHEMERAL/ALIAS колонки
- TTL, skip indexes
- Внешние таблицы (S3, ODBC, MySQL)

**MCP-сервер:**
- 13+ существующих инструментов адаптируются под CH (`system.tables`, `system.columns`, etc.)
- `mcp_explain` → NotSupportedError (CH не имеет EXPLAIN)
- Новые CH-специфичные инструменты: `mcp_ch_list_mergetree`, `mcp_ch_list_dictionaries`, etc.
