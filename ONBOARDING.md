## AI-ассистенты: модель Minimax в периметре Риксофта (prod)

Для работы с AI-ассистентами (ZCode, OpenCode и др.) внутри корпоративного
периметра доступен провайдер `reksoft-sputnik-prd` с моделью Minimax.
Настройки продакшена (проверяйте по актуальному скрину настроек — значения
могут обновляться):

| Параметр | Значение |
|---|---|
| Провайдер | `reksoft-sputnik-prd` |
| Base URL | `https://platform.ai.reksoft.com/api/v1` |
| API-формат | OpenAI Chat Completions (endpoint `/chat/completions`) |
| Модель (Model ID) | `minimax-m2` |
| Context window (input) | `110000` токенов |
| Max output tokens | `16384` токена |
| Доп. модели провайдера | `qwen36:35b-a3b-fp8` (контекст 200K) |

Примечания:

- **Context window 110000 — это лимит на вход** (input + накопленный контекст
  диалога). На выход (генерация) — максимум `16384` токенов на один ответ.
  При настройке клиента указывайте оба значения отдельно.
- API-ключ выдаётся администратором платформы Риксофта; в настройках клиента
  он вводится в поле API key (маскируется). Не коммитить ключи в репозиторий.
- Провайдер совместим с OpenAI-форматом: сторонние клиенты подключаются
  обычным `base_url = https://platform.ai.reksoft.com/api/v1` +
  `api_key = <выданный ключ>`.
- Если модель недоступна/упирается в лимиты — проверьте таймауты клиента
  (продакшен-инференс может отвечать дольше дефолтных 5–30 с).
