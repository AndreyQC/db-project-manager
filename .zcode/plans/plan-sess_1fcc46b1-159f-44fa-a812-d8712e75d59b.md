## §8 USER_INPUT (что предложу с рекомендациями)

Закрывают ROADMAP Q3/Q4/Q5 + новые архитектурные развилки (по аналогии с тем, как Phase 14 расширил Q1/Q2 до DV-1..DV-7). Предварительно ~7 пунктов:

- **CD-1** (= Q3) pre/post идемпотентны vs run-once → рек. всегда идемпотентны.
- **CD-2** (= Q4) git-tag обязателен vs commit → рек. commit по умолчанию, `--require-tag` для prod.
- **CD-3** (= Q5) расположение `migrations/` → рек. `<output>/<db>/migrations/{pre,post}/`.
- **CD-4** имя служебной схемы: хардкод `__deploy` vs configurable → рек. configurable с default `__deploy`.
- **CD-5** `script_watermark` в Phase 10 или отложить → рек. отложить (CD-1 user story помечает опционально).
- **CD-6** checksum алгоритм → рек. SHA-256 (canonical text normalisation: strip whitespace/comments).
- **CD-7** __deploy при validate: всегда создаётся vs флаг → рек. создаётся всегда в temp-БД (для сквозного теста механики).
