## Что это за проект

Python-инструмент (PostgreSQL/Greenplum) для reverse-engineering БД в дерево SQL-файлов,
построения графа зависимостей, validation deploy на пустой temp-БД, сравнения состояний
и controlled-deployment. Стек: Python 3.13, uv, pydantic v2, typer (CLI), PySide6 (GUI),
sqlglot, testcontainers. Пакеты: `domain` → `infrastructure` → `application` →
`presentation`.

## Key decisions & constraints (новое в Phase 11)

- **Dry-run**: gate ничего не применяет; pre-скрипты читаются статически (SG-0).
- **Табличная гранулярность gating** (SG-A): column-diff не нужен для блокировки CD-10.
- **Покрытие = явное объявление** `project.covers` в autodoc (SG-3); gate проверяет
  объявление, не семантику.
- **Нормализованный presence-контракт** (SG-4/SG-5/SG-M): domain БД-агностичен
  (`confidence: FRESH/STALE/UNKNOWN`); адаптер без сигнала → UNKNOWN → «есть данные»
  (fail-safe). Будущие Snowflake/MSSQL/MySQL безопасны по умолчанию.
- **Fail-safe классификация**: EMPTY только при `0 + FRESH`; всё прочее → HAS_DATA.
- **db_type из manifest сверяется с типом подключения** до тяжёлой работы (SG-M).
- Отчёт gate — `safety_gate_report.{md,json}` рядом с `diff_report.json` CompareService.
