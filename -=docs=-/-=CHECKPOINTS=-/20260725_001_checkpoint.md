## What this project is

`db-pm` — CLI + GUI tool (Python 3.13+, PySide6, PostgreSQL/psycopg2) that
reverse-engineers a live DB into a graph of objects, generates idempotent DDL
migration scripts, and deploys them. Phase 7 rebuilt the GUI main window around
an extensible **action panel**: a dropdown of registered actions with unified
«Настроить…»/«Выполнить»/«Копировать CLI» controls and per-action persisted
settings.

## Key design decisions

| Decision | Choice | Why |
|----------|--------|-----|
| Extensibility | Declarative `ActionSpec` registry | New action = one spec; MainWindow/panel unchanged (user requirement: «со временем действий будет больше») |
| Settings persistence | `gui_settings.json` in repo root, gitignored | User choice (U3); local paths, per-machine |
| Graph viewing | External Gephi via existing graphml export | User choice (U4); no new format needed, GEXF → BACKLOG |
| Dropdown placement | Panel right of the connection list, not per-row | U2; per-row (`setIndexWidget`) complexity without UX gain |
| GUI↔CLI drift guard | CliRunner contract test | Generated commands parsed by the real typer app (mocked services) |
| Field naming | `validate_graph` (not `validate`) | pydantic shadows `BaseModel.validate` (lesson 40) |
