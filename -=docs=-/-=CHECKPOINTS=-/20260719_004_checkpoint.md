## What this project is

`db-pm` is a CLI + GUI tool for managing PostgreSQL database schemas. It reverse-engineers
a live DB into a graph of objects, generates idempotent DDL migration scripts,
and deploys them. Built with Python 3.13+, PySide6 GUI, PostgreSQL via psycopg2.

## Key decisions & constraints

| Decision | Choice | Why |
|----------|--------|-----|
| SSH library | paramiko 5.x directly | `sshtunnel` incompatible with paramiko 5.x |
| Port forwarding | Two-thread full-duplex `_pipe` | Single-thread recv blocks; data flows both ways |
| SSH password | Stored encrypted in YAML | Same Fernet as DB password |
| Connection type UI | Dropdown (not checkbox/tab) | Future-proof for MySQL, Snowflake, etc. |
